## 兑换流程：四步，三个地方容易出错

流程本身很短。登录要充值的那个 Steam 账户，在客户端左上角点"游戏"菜单，选"兑换 Steam 钱包充值码"，把卡密粘贴进去，确认后余额立即刷新。

容易出错的是这几处：

**卡密只能兑换一次，兑完即作废。** 登录错账户没有撤回的余地，也不能拆分使用，一张卡对应一次兑换。

**提示"代码无效"先查空格。** 复制时多一个空格、少一个字符都会失败，确认无误还不行就联系客服查卡密状态。

## 为什么不建议折腾虚拟卡

用 U 卡这类虚拟卡直接绑 Steam，失败率高到不值得试。Steam 会读取发卡行的 BIN（卡号前六位），把已知的虚拟卡、预付费卡卡段直接标记为高风险；账单地址校验（AVS）对不上发卡行记录也会被拒；部分卡段还会被强制走 3DS 验证，虚拟卡在这一步经常过不去。就算侥幸绑上，首次小额可能放行，金额一大或次数一多，风控照样把卡踢掉。

有攻略提到先用虚拟卡绑 PayPal、再用 PayPal 付 Steam 的绕行办法，作者自己也说明成功率不是 100%，Steam 会对 PayPal 做二次校验。为了充值去开一张卡、再赌一次风控，成本比直接买卡密高得多。
